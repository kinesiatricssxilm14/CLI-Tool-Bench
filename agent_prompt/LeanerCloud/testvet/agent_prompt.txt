<Project_Overview>
CLI Tool Name: testvet
Repository Name: testvet
Core Functionality Description:
A static analysis tool that identifies missing test coverage, low coverage functions, and misplaced test functions in Go projects. It parses Go source files to find functions not called from any test, identifies tests that primarily call functions from a different source file, and can use statement coverage data to find functions below a specified threshold. It supports filtering out private (unexported) functions, toggling coverage-based filtering, and verbose logging.
</Project_Overview>
