<Project_Overview>
**CLI Tool Name**: jsonata
**Repository Name**: jsonata
**Core Functionality Description**:
This is a command-line tool for processing JSON data using JSONata expressions. The tool reads a JSONata expression and a JSON input, evaluates the expression against the data, and outputs the result. It supports reading the expression and input from files, providing variable bindings from a separate file, and controlling output formatting (e.g., compact vs. pretty-printed) and character encoding.
</Project_Overview>
