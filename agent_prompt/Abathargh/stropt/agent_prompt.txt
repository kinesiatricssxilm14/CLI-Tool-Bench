<Project_Overview>  CLI Tool Name: stropt

Repository Name: stropt

Core Functionality Description: stropt (struct optimizer) is a CLI tool that analyzes C aggregate types (structs, unions) to obtain statistics such as their size, alignment, and total padding bytes. It parses C code provided either directly as a string or from a source file. Additionally, it can suggest optimized memory layouts to minimize the overall size of the struct, and allows users to specify custom or platform-specific base type sizes and alignments (e.g., 32-bit, AVR, or custom sizes for pointers, ints, longs, etc.). </Project_Overview>
