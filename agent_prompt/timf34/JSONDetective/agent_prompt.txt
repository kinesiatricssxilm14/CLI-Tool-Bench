<Project_Overview>
**CLI Tool Name**: jsondetective
**Repository Name**: jsondetective
**Core Functionality Description**:
This is a CLI tool for analyzing JSON files. Its primary function is to process a given JSON file, infer a schema from its contents, and display it. The tool can identify data types like integers and extract example values. For JSON objects where keys are dynamic (e.g., dates) but values follow a consistent structure, the tool merges these value structures to produce a unified schema.

Additionally, the tool has an experimental feature to generate Python dataclass code based on the inferred schema. This can be printed to the console or saved to a specified file, with an option to customize the root class name.
</Project_Overview>
