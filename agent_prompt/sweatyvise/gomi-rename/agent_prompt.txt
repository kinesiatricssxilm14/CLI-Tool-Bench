<Project_Overview>
**CLI Tool Name**: gomi-rename
**Repository Name**: gomi-rename
**Core Functionality Description**:
This is a CLI tool for renaming files into "hellish" or "junk" file names. It takes one or more file paths as input and renames them by adding a series of decorative and often confusing prefixes and suffixes (e.g., `【重要】`, `_Copy`, `_Backup`, `_Final`). The number of decorations can be controlled via a flag. The tool also supports a dry-run mode to preview the generated filenames without actually modifying the file system.
