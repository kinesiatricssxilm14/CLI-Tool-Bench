<Project_Overview>
**CLI Tool Name**: `outlier-detect`
**Repository Name**: `outlier-detect`
**Core Functionality Description**:
This tool detects outliers in 2D (x, y) datasets. It reads data from a CSV file, calculates the Cook's distance for each data point, and identifies points as outliers if their Cook's distance exceeds a specified threshold. The results, including the original data, Cook's distance, and an outlier flag, can be saved to a new CSV file. The tool also supports a verbose mode for logging its operations.
</Project_Overview>
