<Project_Overview>
**CLI Tool Name**: journal-cli
**Repository Name**: journal-cli
**Core Functionality Description**:
This is a command-line tool designed for quick interaction with a local directory of notes. The tool allows users to manage a collection of notes structured into `journals` and `pages` subdirectories.

Key functionalities include:
- Appending new entries to specific daily journal files or named page files.
- Creating new page files on the fly if they don't exist when appending content.
- Supporting content appending directly from a command-line argument or from STDIN.
- Formatting appended entries as markdown list items, with support for custom indentation levels.
- Printing the content of a specific journal or page to standard output.
- Searching for page files by matching a substring in the filename.
- Searching through the content of all page files using a regular expression and reporting the matching lines.
</Project_Overview>
