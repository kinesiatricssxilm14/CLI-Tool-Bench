<Project_Overview>
**CLI Tool Name**: fsm-proc
**Repository Name**: fsm-proc
**Core Functionality Description**:
This is a CLI tool for processing and editing files based on a set of rules defined as a state machine. It reads an input file record-by-record (defaulting to line-by-line) and applies actions based on the current state and whether the current record matches a specified regular expression. Supported actions include printing data, and transitioning to a new state. This allows for complex, stateful text processing. The tool can take the state machine program either from a file or as a command-line string.
</Project_Overview>
