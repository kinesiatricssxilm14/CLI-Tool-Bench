# Showcase: LLM Generated Repositories

This folder contains a couple of representative "success" cases where an LLM autonomous agent successfully generated a full CLI tool from scratch (achieving near 100% Semantic Match and passing both the Execution and Side-Effect validation gates).

These examples are provided directly in the repository so reviewers can easily inspect the quality and structure of the code generated by the agents, without needing to download the full >1GB results archive from Google Drive.

## Featured Examples

1. **`deepseek-v3.2_openhands_local-gitingest`**
   - **Language:** Go
   - **Task:** `bigwhite/local-gitingest` (Batch File Processing)
   - **Agent/Model:** OpenHands with DeepSeek-V3.2
   - **Description:** An agent-generated Go repository handling directory traversals and text extraction. Notice how the agent independently planned the `main.go` and `go.mod` structure.

2. **`kimi-k2.5_miniswe_mp4analyzer`**
   - **Language:** Python
   - **Task:** `andrewx-bu/mp4analyzer` (Utility Libraries)
   - **Agent/Model:** Mini-SWE-Agent with Kimi-k2.5
   - **Description:** A Python package using `pyproject.toml` and standard CLI argument parsing. Demonstrates that the agent correctly sets up package entry points to be installable and runnable as a system CLI.

*Note: The metadata (like `run.log`, evaluation `output.json`) and the oracle `.git` files have been stripped from these preview folders to save space. The directories contain purely the code generated by the LLM agent.*
