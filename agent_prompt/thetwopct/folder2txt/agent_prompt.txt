<Project_Overview>
**CLI Tool Name**: dir-consolidator
**Repository Name**: dir-consolidator
**Core Functionality Description**:
This is a CLI tool that converts the contents of a local folder into a single text file. It recursively processes all text files within a directory and its subdirectories, concatenating their contents into a single output file. The output format includes clear separators and metadata (file path, size) for each file. The tool provides options to specify the output file path, set a file size threshold, include all files, and enable a debug mode.
</Project_Overview>
