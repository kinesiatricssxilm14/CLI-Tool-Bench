<Project_Overview>
**CLI Tool Name**: source-to-llm
**Repository Name**: source-to-llm
**Core Functionality Description**:
The CLI tool extracts source code from project files and formats it for use in prompts. It recursively scans a specified directory for files matching given glob patterns. It can also exclude files based on ignore patterns. The tool then concatenates the content of the matched files and prints the result to standard output. Each file's content is clearly demarcated with a header indicating its relative path and surrounded by separator lines. This is useful for preparing a codebase for AI analysis, code review, or documentation tasks.
