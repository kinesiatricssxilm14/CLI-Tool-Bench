<Project_Overview>
**CLI Tool Name**: vale-cli
**Repository Name**: vale-cli
**Core Functionality Description**:
This tool is a server that integrates a prose linting engine into AI coding assistants and other compatible tools through a standard communication protocol over stdio.

The server's main functions are:
- To start and run as a background process, listening for JSON-based requests on standard input.
- To check for the presence and version of the underlying linting engine.
- To automatically discover linter configuration files (`.vale.ini`) in the current working directory.
- To allow specifying an explicit configuration file path via the `VALE_CONFIG_PATH` environment variable.
- To provide a debug mode for verbose logging using a `--debug` flag.
- To process requests to lint a specified file (`check_file` tool) and check the linter's installation status (`vale_status` tool).
</Project_Overview>
