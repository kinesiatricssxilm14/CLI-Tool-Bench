<Project_Overview>
**CLI Tool Name**: go-import-formatter
**Repository Name**: go-import-formatter
**Core Functionality Description**:
This is a CLI tool for formatting Go import statements while maintaining a stable order. It organizes imports into four distinct groups: Standard Library, Third-Party Libraries, Organization Modules, and Local Project Imports.

The tool can read a target Go file, reformat its import block, and either print the formatted content to standard output or write it back to the original file. Its behavior can be customized through command-line flags or a `goreg.toml` configuration file. Key features include defining custom prefixes for local and organization modules, specifying a custom order for import groups, and other formatting adjustments. The tool can also be instructed to ignore the configuration file via an environment variable.
</Project_Overview>
