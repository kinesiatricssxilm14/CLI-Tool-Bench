<Project_Overview>
**CLI Tool Name**: `yescrypt_crack`
**Repository Name**: `yescrypt_crack`
**Core Functionality Description**:
This is a command-line tool for cracking yescrypt hashes. It takes a file containing one or more yescrypt hashes and a wordlist (from a file or standard input) and attempts to find the corresponding plain-text passwords. It supports multi-threading to speed up the process and can output cracked pairs to a specified file or to standard output. The tool also provides periodic status updates during the cracking process.
</Project_Overview>
