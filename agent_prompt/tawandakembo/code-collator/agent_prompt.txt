<Project_Overview>
**CLI Tool Name**: code-collator
**Repository Name**: code-collator
**Core Functionality Description**:
The CLI tool's primary function is to collate an entire codebase from a specified directory into a single, organized Markdown file. It recursively scans the directory, reads the content of each file, and appends it to the output file. The tool supports ignoring files and directories specified in a `.gitignore` file found in the source directory. It also provides an option to strip comments and docstrings from the code before adding it to the final Markdown file. The output file name and location can be customized.
</Project_Overview>
