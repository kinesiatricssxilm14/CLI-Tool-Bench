<Project_Overview>
**CLI Tool Name**: depcycle
**Repository Name**: depcycle
**Core Functionality Description**:
A command-line tool to analyze Python projects. It scans the project's source code, discovers module dependencies, and generates a visual dependency graph. The tool can detect and report circular dependencies. It supports multiple output formats (PNG, SVG, HTML) and allows for filtering of modules (e.g., excluding third-party libraries, standard library modules, or files matching specific glob patterns).
</Project_Overview>
