**CLI Tool Name**: ymldiff
**Repository Name**: ymldiff

This project is to create an intelligent YAML comparison tool. Unlike simple text diffs, this tool understands YAML structure to provide meaningful output. It identifies and reports additions, deletions, and modifications between two YAML files. The output format can be controlled via flags, such as disabling document separator comments and colorization.
