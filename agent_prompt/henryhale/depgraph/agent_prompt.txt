<Project_Overview>
**CLI Tool Name**: depgraph
**Repository Name**: depgraph
**Core Functionality Description**:
This is a CLI tool for visualizing a codebase's dependency graph to help developers understand its structure. The tool is language-agnostic, using regular expressions to match import and export statements. It analyzes a target directory, builds a dependency graph from the files and their imports, and then outputs the graph in a specified format.

Supported features based on the requirements:
- Analyzes a specified directory (defaults to the current directory).
- Supports multiple languages by filtering files, including `js`, `ts`, `c`, and `cpp`.
- Outputs dependency graphs in multiple formats: `mermaid` (default), `json`, and `jsoncanvas`.
- Allows ignoring specified directories from the analysis.
- Supports defining path aliases for import resolution.
- Can write the output to a specified file or to standard output.
</Project_Overview>
