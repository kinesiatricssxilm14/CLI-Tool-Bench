<Project_Overview>
CLI Tool Name: obfuscator
Repository Name: obfuscator
Core Functionality Description:
A CLI tool to obfuscate R code by renaming variables, functions, and file names while preserving functionality. It parses R code to identify identifiers, generates obfuscated names based on a provided encryption key, and consistently replaces them throughout the codebase. It also supports prepending license text to obfuscated files, protecting specific tokens from being renamed, ignoring specific directories, and reversing the process via a deobfuscation flag.
