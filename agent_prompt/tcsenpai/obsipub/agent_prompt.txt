<Project_Overview>
**CLI Tool Name**: md-to-epub
**Repository Name**: md-to-epub
**Core Functionality Description**:
The user wants a CLI tool that converts a directory of Markdown files into a single, well-formatted EPUB ebook.

The tool should be able to:
- Recursively scan a source directory (a "vault") for Markdown files (`.md`).
- Map the folder hierarchy to EPUB chapter structure, automatically generating chapter titles from folder names.
- Process Markdown files by converting wikilinks (e.g., `[[note2]]`) into standard relative links.
- Handle embedded attachments (e.g., `![[image.png]]`), copying them into the final EPUB.
- Allow for customization of the book's metadata, such as title and author.
- Provide options to include or exclude attachments, and to keep or remove tags (e.g., `#project`).
- Generate detailed logs for debugging purposes.

**Crucial External Dependency**: The tool's core functionality relies on the **`pandoc`** command-line utility. The agent must assume `pandoc` is pre-installed and available in the system's PATH. The implementation should generate and execute `pandoc` commands to create the final EPUB file.
</Project_Overview>
