<Project_Overview>
**CLI Tool Name**: malang
**Repository Name**: malang
**Core Functionality Description**:
This project is a compiler and interpreter for a custom programming language. The core functionality is to take a source file as input, compile it, and execute it. The language supports a `parayu("...")` function, which prints the provided string to the standard output.

The tool also provides several flags to inspect the intermediate stages of the compilation process:
- `-tokens`: Displays the sequence of lexical tokens generated from the source code.
- `-ast`: Displays the Abstract Syntax Tree (AST) constructed from the tokens.
- `-gocode`: Displays the final Go code generated by the compiler.

In all cases, after displaying the requested intermediate representation (if any flag is used), the tool proceeds to execute the code.
</Project_Overview>
