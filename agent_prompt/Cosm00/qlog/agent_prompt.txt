<Project_Overview>
**CLI Tool Name**: qlog
**Repository Name**: qlog
**Core Functionality Description**:
This project is a command-line tool for lightning-fast local log search and analysis. The core functionality revolves around a two-step process: indexing and searching. First, the tool indexes log files based on user-provided patterns, creating an efficient local index. This indexing process is designed to be fast. Once indexed, users can perform searches for specific terms across millions of lines in milliseconds. The search results can be displayed with surrounding context lines for better debugging and can also be output in JSON format for programmatic use. The tool also provides commands to display statistics about the created index and to clear the index when it's no longer needed.
</Project_Overview>
