<Project_Overview>
**CLI Tool Name**: jinni
**Repository Name**: jinni
**Core Functionality Description**:
The core function of this CLI tool is to process project files and consolidate their content into a single, structured text output. It is designed to gather the context of a software project by traversing specified directories or files.

The tool intelligently filters which files to include. By default, it respects rules found in `.gitignore` files to exclude irrelevant content like build artifacts or data files. It also has its own built-in filters to exclude dotfiles and other common non-source files.

The output format concatenates the content of each included file. Each file's content is wrapped in a code block and preceded by a header indicating its relative path, like ````path=src/app.py`.

The tool provides several command-line options to customize its behavior:
- Users can specify one or more target paths to process.
- It can be instructed to only list the paths of the files that would be included, rather than their content.
- The output can be written to a file instead of standard output.
- Advanced filtering options allow for including or excluding files and directories based on keywords, paths, and patterns.
</Project_Overview>
