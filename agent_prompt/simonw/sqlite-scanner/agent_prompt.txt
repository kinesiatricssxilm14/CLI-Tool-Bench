<Project_Overview>
**CLI Tool Name**: sqlite-scanner
**Repository Name**: sqlite-scanner
**Core Functionality Description**:
The CLI tool recursively scans one or more specified directory paths to find SQLite database files. If no paths are provided, it defaults to scanning the current directory (`.`). File identification is performed by checking the first 16 header bytes for the magic string `SQLite format 3\x00`, not by relying on file extensions. The tool is designed for speed, utilizing a configurable number of parallel workers. It outputs the absolute paths of matching files. The output format can be controlled via flags to be plain text, a single pretty-printed JSON object, or newline-delimited JSON (JSONL). An option is also available to include the file size in the output.
</Project_Overview>
