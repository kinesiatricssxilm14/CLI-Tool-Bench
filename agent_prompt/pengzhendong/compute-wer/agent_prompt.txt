<Project_Overview>
**CLI Tool Name**: compute-wer
**Repository Name**: compute-wer
**Core Functionality Description**:
This project requires the creation of a command-line tool for evaluating speech recognition systems by computing Word Error Rate (WER) and Sentence Error Rate (SER). The tool compares reference (ground truth) text with hypothesis (transcribed) text from input files.

Key features to be implemented include:
- Comparison of text on either a word-level (default) or character-level.
- Case-sensitive and case-insensitive matching modes.
- Ability to remove XML-style tags (e.g., `<noise>`) from text before comparison.
- Option to ignore a predefined list of words from a separate file during calculation.
- Filtering of results to show only utterances with a WER below a specified threshold.
- Sorting the output report by utterance ID or by WER in ascending order.
- Aligning the output based on the hypothesis text instead of the reference text.
- Generating a detailed report for each utterance pair, including alignment and error statistics (Correct, Substitution, Deletion, Insertion), and an overall summary report.
</Project_Overview>
