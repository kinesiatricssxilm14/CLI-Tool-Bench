<Project_Overview>
**CLI Tool Name**: eyeling
**Repository Name**: eyeling
**Core Functionality Description**:
This tool is a compact reasoner for a specific data notation. It processes input files containing facts and rules, performing forward and backward chaining. By default, it outputs newly derived facts. When specific query directives are present in the input, it outputs only the unique instantiated conclusion triples of those queries. The tool also supports outputting the Abstract Syntax Tree (AST) of the input file and including detailed proof comments for derived facts.
</Project_Overview>
