<Project_Overview>
**CLI Tool Name**: sql-mongo-converter
**Repository Name**: sql-mongo-converter
**Core Functionality Description**:
This is a command-line utility for bidirectional conversion between SQL queries and MongoDB query objects. It provides two main functions:
1.  `sql2mongo`: Converts SQL statements into their equivalent MongoDB JSON representation. It can handle `CREATE TABLE` statements by converting them to `createCollection` operations with schema validation, and `SELECT` statements with `LIKE` clauses by converting them to `find` operations using `$regex`.
2.  `mongo2sql`: Converts MongoDB JSON query objects into their equivalent SQL statements. It can handle `find` operations with logical operators like `$or` and comparison operators like `$lt`, and `updateMany` operations with `$set` by converting them to SQL `UPDATE` statements.

The tool supports providing the input query/object directly as a command-line argument or by reading it from a specified file.
</Project_Overview>
