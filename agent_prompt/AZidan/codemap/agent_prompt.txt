<Project_Overview>
**CLI Tool Name**: codemap
**Repository Name**: codemap
**Core Functionality Description**:
This CLI tool is a structural indexer for codebases. Its primary function is to scan a repository, identify code symbols (like classes, functions, and methods) along with their exact line ranges, and save this information into a local index stored in a `.codemap` directory.

The tool provides functionalities to:
- Initialize the index for a project (`init`).
- Find symbols by name, with options for type filtering and fuzzy matching (`find`).
- Display the indexed structure of a file (`show`).
- Check for files that have been modified since the last indexing (`validate`).
- Update the index for specific files or all modified files (`update`).
- Display statistics about the indexed codebase (`stats`).
- Validate line ranges within a file (`lines`).
- Install Git hooks to automate index updates (`install-hooks`).

The core purpose is to enable fast and precise lookups of code locations without needing to read entire files.
</Project_Overview>
