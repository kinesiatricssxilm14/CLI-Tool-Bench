CLI Tool Name: pygha
Repository Name: pygha
Core Functionality Description:
A Python-native CI/CD framework CLI tool for defining and transpiling pipelines to GitHub Actions YAML files. It provides commands to initialize a new pipeline project structure and to build/generate GitHub Actions workflows (`.yml` files) from Python definitions. It supports customizing the source directory for Python pipeline files, the output directory for the generated YAML workflows, and a cleanup mechanism to remove unregistered workflow files.
