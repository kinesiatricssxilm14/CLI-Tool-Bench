<Project_Overview>
**CLI Tool Name**: todo-bridge
**Repository Name**: todo-bridge
**Core Functionality Description**:
This is a CLI tool that converts to-do lists from various formats (CSV, Markdown, and Todo.txt) into a specific, structured JSON format. It supports creating tasks, subtasks, projects, and tags based on the input file's content. The tool can either generate a new JSON data structure from scratch or merge the new tasks into an existing one. The format of the input file is detected automatically based on its extension (.csv, .md, .txt).
</Project_Overview>
