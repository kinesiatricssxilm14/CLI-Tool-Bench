<Project_Overview>
**CLI Tool Name**: ccv
**Repository Name**: ccv
**Core Functionality Description**:
This is a CLI tool for inspecting conversation history files stored in JSONL format, with a specific focus on identifying and analyzing "compaction" events. A compaction event is a process where a long conversation is summarized to preserve context.

The tool provides two main functionalities:
1.  It can scan a directory of projects to find all conversation files, analyze them for compaction events, and display a summary table showing metrics like line count and number of compactions for each conversation.
2.  It can analyze a single specified conversation file and print a detailed report for each compaction event found within it, including the trigger type and the full summary text.
</Project_Overview>
