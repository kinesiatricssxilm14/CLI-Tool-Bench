<Project_Overview>
CLI Tool Name: prompt-scanner
Repository Name: prompt-scanner
Core Functionality Description:
A language-aware CLI tool that automatically surfaces natural-language prompts for LLMs buried in code, templates, or config files. It recursively scans a given directory path to find potential prompts based on configurable heuristics like minimum length, variable keywords, content keywords, and placeholder patterns. It supports outputting results in text or JSON format, optionally ignoring files via `.gitignore`, scanning config files, and toggling the display of file paths and line numbers.
</Project_Overview>
