<Project_Overview>
**CLI Tool Name**: `git-metrics`
**Repository Name**: `git-metrics`
**Core Functionality Description**:
This is a command-line utility that analyzes Git repositories to provide comprehensive insights about repository history, structure, and growth patterns. The tool examines a repository's Git object database to reveal historical trends and contributor activity.

Key features include:
- Repository metadata analysis (first/last commit, age).
- Year-by-year growth statistics for Git objects (commits) and their on-disk size.
- Directory structure analysis with size impact indicators.
- Identification of largest files in the repository.
- File extension distribution analysis.
- Contributor statistics showing top committers and authors over time.
</Project_Overview>
