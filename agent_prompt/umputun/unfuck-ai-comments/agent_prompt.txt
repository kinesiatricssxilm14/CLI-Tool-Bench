<Project_Overview>
**CLI Tool Name**: unfuck-ai-comments
**Repository Name**: unfuck-ai-comments
**Core Functionality Description**:
The CLI tool is designed to process Go source files to normalize the capitalization of comments. Its primary function is to convert comments found inside function bodies and struct definitions to lowercase, enhancing code consistency.

Key features include:
- **Selective Processing**: It intelligently modifies only comments within function bodies and struct definitions, while preserving package-level comments and documentation comments for functions and types.
- **Two Conversion Modes**:
  1.  **Default Mode**: Converts only the first character of a comment to lowercase.
  2.  **Full Mode (`--full`)**: Converts the entire comment string to lowercase.
- **Preservation Rules**:
  - Special indicator comments (e.g., `TODO:`, `FIXME:`) are left unchanged.
  - `PascalCase` and `camelCase` identifiers within comments are preserved to maintain readability and references to code elements.
- **Output Control**:
  - `run`: Modifies files in-place.
  - `diff`: Shows a diff of potential changes without altering files.
  - `print`: Prints the modified content to standard output.
- **Additional Options**:
  - `--fmt`: Formats the processed Go code using `gofmt`.
  - `--backup`: Creates a `.bak` backup of any file that is modified.
  - `--skip`: Skips processing for files or directories that match a given pattern.
</Project_Overview>
