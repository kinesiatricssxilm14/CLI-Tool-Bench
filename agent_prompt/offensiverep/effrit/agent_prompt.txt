<Project_Overview>
CLI Tool Name: effrit
Repository Name: effrit
Core Functionality Description:
A Go Efferent and Afferent package metric calculator. It scans a project for Go files and packages, gathering all defined packages to calculate metrics such as Instability, Abstractness, and Distance from the main sequence. The tool outputs a formatted ASCII table of the metrics to the standard output and dumps the detailed package data as a JSON file (`.effrit_package_data.json`) directly into the project root.
</Project_Overview>
