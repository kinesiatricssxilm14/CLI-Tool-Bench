<Project_Overview>
**CLI Tool Name**: graphtty
**Repository Name**: graphtty
**Core Functionality Description**:
A CLI tool that renders a directed graph from a JSON file as ASCII/Unicode art in the terminal. The tool reads a JSON file specifying nodes and edges, and generates a text-based visual representation. It supports options for using plain ASCII characters, hiding node types, applying color themes, and controlling the layout dimensions like width, depth, and breadth.
</Project_Overview>
