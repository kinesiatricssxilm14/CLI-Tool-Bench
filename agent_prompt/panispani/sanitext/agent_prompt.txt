**CLI Tool Name**: sanitext
**Repository Name**: sanitext
**Core Functionality Description**:
This is a command-line tool for processing text strings to detect and sanitize unwanted characters. The primary function is to take a string input and convert it to a clean, ASCII-like representation by replacing or removing non-standard characters. The tool also provides functionality to only detect these characters without performing sanitization, control the verbosity of the output, and specify allowlists for characters that should not be sanitized.
