<Project_Overview>
**CLI Tool Name**: remove-unused-vars
**Repository Name**: remove-unused-vars
**Core Functionality Description**:
This tool processes JSON-formatted linter reports to automatically remove unused variables and functions from source code files. It parses the report, which specifies the file paths and exact locations of the unused code, and then modifies the corresponding source files to remove the reported definitions. The tool can receive the JSON report either from a file path provided as a command-line argument or by reading from standard input.
</Project_Overview>

#### Command Category: `remove-unused-vars <file>`
- **Function and Parameter Description**:
  The tool is invoked with a single argument, which is the path to a JSON file. This file contains a linter report detailing unused variables. The tool will parse this file and modify the source code files mentioned within the report.
- **Execution Context and Sample**:
  **1. Preparation**:
  The following files are created in the `/test_data/` directory:
  - `/test_data/report_file_input_4.json`: A JSON file containing the linter report. It specifies that in `source_file_input_4.js`, the variable `unused_var` and the function `unused_func` are unused, providing their exact locations.
    ```json
    [
      {
        "filePath": "/test_data/source_file_input_4.js",
        "messages": [
          {
            "ruleId": "no-unused-vars",
            "message": "'unused_var' is defined but never used.",
            "line": 1,
            "column": 7,
            "endLine": 1,
            "endColumn": 17
          },
          {
            "ruleId": "no-unused-vars",
            "message": "'unused_func' is defined but never used.",
            "line": 2,
            "column": 10,
            "endLine": 2,
            "endColumn": 21
          }
        ]
      }
    ]
    ```
  - `/test_data/source_file_input_4.js`: The target source code file containing both unused and used code.
    ```javascript
    const unused_var = 1;
    function unused_func() {}
    const used = 2; console.log(used);
    ```
  **2. Command**:
  `remove-unused-vars /test_data/report_file_input_4.json`
  **3. Oracle Result**:
  ```json
  {
      "exit_code": 0,
      "stdout": "",
      "fs_diff": {
          "/test_data/source_file_input_4.js": {

          }
      }
  }
  ```
- **Deep Sample Analysis (Implementation Logic Reference):
  - Initial State Analysis: Before execution, a source file `/test_data/source_file_input_4.js` exists with three lines of code. A separate JSON report file `/test_data/report_file_input_4.json` lists the first two definitions (`unused_var` and `unused_func`) as unused.
  - Command Behavior Analysis: The program is called with the path to the report file. It must read and parse this JSON file. The JSON structure is an array of objects, where each object contains a `filePath` and a `messages` array. The tool iterates through these messages to identify which file to modify and what code ranges to remove. The tool does not produce any standard output.

Specifically, the first two lines (`const unused_var = 1;` and `function unused_func() {}`) are deleted, leaving only the line with the used code.
