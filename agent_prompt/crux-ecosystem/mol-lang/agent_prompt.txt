<Project_Overview>
**CLI Tool Name**: mol
**Repository Name**: mol-cli
**Core Functionality Description**:
This project involves creating a command-line tool for a custom scripting language. The language is designed for data pipelines and features a special pipe operator `|>` for chaining operations. The CLI tool serves as an interpreter and a comprehensive toolchain for this language.

Key functionalities include:
- **Script Execution**: Running scripts from `.mol` files. A standout feature is the automatic tracing of multi-stage pipelines (3+ stages), which provides detailed, timed feedback on each step of the data flow. This tracing can be disabled with a flag.
- **AST Parsing**: Parsing a script and displaying its Abstract Syntax Tree (AST) in a human-readable format.
- **Transpilation**: Converting scripts into either Python or JavaScript code.
- **Building Standalone Applications**: Compiling scripts into self-contained, runnable formats, including:
    - A standalone HTML file with an embedded JS runtime for browser execution.
    - A standalone JavaScript file.
    - A Node.js module.
- **Test Runner**: A built-in capability to discover and execute test blocks defined within the scripts.
</Project_Overview>
