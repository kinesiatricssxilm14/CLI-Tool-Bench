**Repository Name**: `CMIP7_data_request_api_config`
**Core Functionality Description**:
This is a command-line utility for managing a configuration file. The tool interacts with a YAML configuration file named `.CMIP7_data_request_api_config` located in the user's home directory.

Its core functionalities include:
- **Initialization**: Automatically creates the configuration file with a set of default values if it doesn't exist.
