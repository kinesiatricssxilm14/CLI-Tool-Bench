<Project_Overview>
**CLI Tool Name**: `backing-tracks`
**Repository Name**: `backing-tracks`
**Core Functionality Description**:
This project involves creating a command-line tool that functions as a backing track generator. The tool parses simple YAML-based files (with a `.btml` extension) that define musical compositions. These files specify track properties like title, key, tempo, and style, along with a chord progression, bass line style, and drum pattern style.

Based on the provided samples, the core functionality is to read these `.btml` files and export them into two different formats:
1.  **MIDI Export**: Generate a standard MIDI file (`.mid`) containing separate tracks for chords, bass, and drums based on the input file's specifications.
2.  **Strudel Export**: Generate a JavaScript file (`.strudel.js`) containing code compatible with the Strudel live coding environment, translating the musical structure into Strudel's syntax.
</Project_Overview>
