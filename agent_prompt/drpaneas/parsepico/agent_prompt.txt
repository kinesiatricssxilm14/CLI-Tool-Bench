<Project_Overview>
**CLI Tool Name**: parsepico
**Repository Name**: parsepico
**Core Functionality Description**:
This CLI tool is designed to parse a proprietary game cartridge file format (`.p8`). It extracts graphics and map data from specific sections within the file and converts them into standard image and data formats.

The tool's primary functions are:
- It reads the `__gfx__` (graphics) and `__map__` (map) sections of a `.p8` cartridge file.
- It generates a `map.png` image rendering the tilemap data.
- It generates a `spritesheet.png` image by stacking sprite sheet sections.
- It creates a `sprites/` directory containing individual 8x8 sprite images (`sprite_NNN.png`) and section images (`section_X.png`).
- It produces `spritesheet.json` and `map.json` files, which contain structured metadata about the extracted sprites and map layout, respectively.
- It supports flags (`--3`, `--4`) to treat specific sprite memory regions as "dual-purpose," using them as additional map data. This alters the number of exported sprites and the dimensions of the generated map.
- It includes a `--clean` option to remove any previously generated output files and directories before running the extraction process.
</Project_Overview>
