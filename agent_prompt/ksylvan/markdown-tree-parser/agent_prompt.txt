<Project_Overview>
**CLI Tool Name**: md-tree
**Repository Name**: md-tree
**Core Functionality Description**:
This is a command-line tool for parsing and manipulating markdown files as tree structures. Its capabilities include:
- Listing all headings in a markdown file, either in a human-readable tree format or as a JSON object.
- Extracting specific sections based on heading text, or all sections of a given level. The extracted content can be printed to standard output or saved to individual files.
- Displaying the document's heading structure as a visual tree.
- Searching for elements within the markdown document using simple selectors (e.g., "link").
- Generating and displaying document statistics, such as word count, paragraph count, and a breakdown of headings by level.
- Checking for broken links within a file, with an option to recursively check links in linked local markdown files.
- Generating a markdown-formatted Table of Contents (ToC) from the document's headings, with an option to control the maximum heading depth.
</Project_Overview>
