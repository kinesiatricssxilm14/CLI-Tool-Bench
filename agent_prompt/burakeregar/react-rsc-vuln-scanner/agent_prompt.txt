<Project_Overview>
**CLI Tool Name**: scan-rsc-vuln
**Repository Name**: scan-rsc-vuln
**Core Functionality Description**:
This is a CLI tool designed to scan a specified directory for Node.js projects. It recursively finds all `package.json` files, parses their dependencies (`dependencies`, `devDependencies`, `peerDependencies`), and checks them against a known list of security vulnerabilities related to React Server Components. The tool identifies both directly vulnerable packages and potentially affected frameworks, then outputs a comprehensive, color-coded report to the console. The report includes a summary of findings, details on vulnerable projects, and actionable remediation instructions.
</Project_Overview>
