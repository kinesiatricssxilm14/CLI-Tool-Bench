<Project_Overview>
**CLI Tool Name**: ingress-translator
**Repository Name**: ingress-translator
**Core Functionality Description**:
This CLI tool translates Kubernetes Ingress resources, specifically those with certain NGINX annotations, into corresponding Gateway API and related Custom Resource Definition (CRD) resources. It reads Ingress definitions from a file and outputs the translated resources in either YAML or JSON format. Based on the provided examples, the tool supports converting annotations for features like rate limiting, URL rewriting, session affinity, and CORS policies.
</Project_Overview>
