<Project_Overview>
**CLI Tool Name**: json-demuxer
**Repository Name**: json-demuxer
**Core Functionality Description**:
The project is a CLI tool for code generation. Its primary function is to scan a Python project directory, identify specific Pydantic-style model classes, and automatically generate corresponding "demuxer" classes. These demuxer classes are designed to help process streaming JSON data asynchronously, allowing parts of a JSON object to be used before the entire response has been received.

The tool works by looking for classes that inherit from a provided `StreamableModel` base class. It then generates new classes with a `Demuxer` suffix, which can be used to handle the data streams.
</Project_Overview>
