<Project_Overview>
**CLI Tool Name**: hashcrafter
**Repository Name**: hashcrafter
**Core Functionality Description**:
This CLI tool is designed to find a matching plaintext for a given hash. It operates by taking a list of strings from an input file and generating a vast number of combinations from them. The tool generates permutations from all possible subsets of the input strings, joins them with a set of separators, calculates a hash for each resulting string, and compares it against a target hash provided by the user.

Key features demonstrated by the requirements include:
- Reading a list of strings from a file, with one string per line.
- Generating combinations from permutations of all non-empty subsets of the input strings.
- Joining string combinations with separators. It supports a default list of separators and allows the user to specify a custom, comma-delimited list. An empty string is also treated as a potential separator.
- Supporting multiple hash algorithms (e.g., `sha256`, `sha384`, `sha3-224`). The default is `sha256`.
- A verbose mode (`-v`) to print detailed progress, including the number of strings loaded, separators being used, and the total number of permutations generated before starting the search.
- Upon finding a match, it prints the successful plaintext combination.
</Project_Overview>
