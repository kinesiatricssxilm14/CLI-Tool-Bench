# CLI-Tool-Bench

## Structure
All prompts generated by the repositories are located in the `agent_prompt` folder.
The differential test code for all repositories is located in the `run_differential_test` folder. `run_multi.py` is the entry point, and the `repo` folder contains `start.py` files for each repository, used to start differential tests.
```
run_differential_test/
├── repo
├── BaseRepoAdapter.py
├── DiffTestEngine.py
├── full_name.txt
└── run_multi.py
```
All the repositories are listed in `run_differential_test/full_name.txt`.
