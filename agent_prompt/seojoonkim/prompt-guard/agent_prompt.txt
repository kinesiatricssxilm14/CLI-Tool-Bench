<Project_Overview>
**CLI Tool Name**: prompt-guard
**Repository Name**: prompt-guard
**Core Functionality Description**:
This is a command-line tool designed to analyze text messages for potential security threats. It detects various malicious inputs, such as injection attacks, attempts to access sensitive files, and jailbreak prompts. Based on its analysis, it assigns a severity level (e.g., HIGH, CRITICAL) and a recommended action (e.g., block, block_notify). The tool can output its findings in a human-readable format or as a structured JSON object. Additionally, every analysis event is logged to a security log file. The tool's detection behavior can be customized via command-line flags for sensitivity and external configuration files.
</Project_Overview>
