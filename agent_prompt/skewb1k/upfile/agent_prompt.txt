<Project_Overview>
CLI Tool Name: upfile
Repository Name: upfile
Core Functionality Description:
A CLI tool for syncing files across multiple projects. It helps manage shared configuration files by identifying each file by a unique filename associated with an "upstream" version (the source of truth). Users can add multiple instances of the same file across different projects (called "entries"). These entries can be pushed to the upstream to update the source of truth, and pulled or synced from it to keep all project files consistent. Supported operations include adding files to tracking, listing tracked files and their status, pushing changes, pulling/syncing changes, viewing diffs, removing entries, dropping tracked files entirely, renaming files, showing upstream content, and checking directory status.
</Project_Overview>
