<Project_Overview>
**CLI Tool Name**: crypto-scanner
**Repository Name**: crypto-scanner
**Core Functionality Description**:
The CLI tool is designed to analyze cryptographic assets within a given directory. It scans for items such as certificates, keys, and secrets. Based on its findings, it generates a new Cryptographic Bill of Materials (CBOM) or enriches an existing one. The output is a CycloneDX v1.6 compliant BOM in JSON format, printed to standard output. The tool's functionality is modular, relying on a system of plugins that can be selectively enabled or disabled. It also supports ignoring specified file paths during the scan.
</Project_Overview>
