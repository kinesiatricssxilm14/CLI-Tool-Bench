<Project_Overview>
CLI Tool Name: simplescript
Repository Name: simplescript
Core Functionality Description:
A lightweight compiled programming language designed for native execution. The CLI tool provides a built-in toolchain to parse, transpile, and execute `.ss` script files. It supports static typing (`str`, `int`, `float`), immutable constants, variables, basic arithmetic, exclusive range loops (`for i in 0..X`), and a built-in print function (`say`). The tool can either execute a script immediately in memory or compile it into a native executable binary.
