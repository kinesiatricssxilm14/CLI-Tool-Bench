<Project_Overview>
**CLI Tool Name**: `subwords`
**Repository Name**: `subwords`
**Core Functionality Description**:
This tool processes a list of subdomains, which can be provided either from a file or via standard input. Its primary function is to extract individual words from these subdomains by splitting them using delimiters such as dots (`.`), hyphens (`-`), and underscores (`_`). After extraction, the tool compiles a list of unique words, sorts them alphabetically, and prints them to the standard output. It also offers options to display the frequency count for each word and to limit the total number of words in the output.
</Project_Overview>
