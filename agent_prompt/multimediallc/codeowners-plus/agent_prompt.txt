<Project_Overview>
**CLI Tool Name**: cli
**Repository Name**: cli
**Core Functionality Description**:
This project is a command-line utility for managing code ownership within a repository. It uses `.codeowners` files to define which users or teams own specific files or directories. The tool can parse these files to perform several key functions:

1.  **Validate Configuration**: It can check `.codeowners` files for syntactical correctness.
2.  **Identify Unowned Files**: It can scan the repository to find any files that are not covered by any ownership rule.
3.  **Determine File Owners**: Given one or more file paths, it can identify and display the designated owner(s).

The `.codeowners` file format supports:
-   Glob-based patterns for matching files (e.g., `*.go`, `**/*.js`).
-   Directory-based ownership (e.g., `docs/`).
-   Fallback owners for any file (`*`).
-   Comments starting with `#`.
-   "OR" ownership rules, where any one of the specified owners can provide a review (e.g., `pattern @owner1 @owner2`).
-   Rules are relative to the directory containing the `.codeowners` file.
</Project_Overview>
