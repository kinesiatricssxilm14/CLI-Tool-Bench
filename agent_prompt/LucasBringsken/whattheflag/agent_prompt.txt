<Project_Overview>
**CLI Tool Name**: flag-explainer
**Repository Name**: flag-explainer
**Core Functionality Description**:
A lightweight CLI tool for instantly explaining command-line flags. It helps users understand command-line flags and options for many popular CLI tools directly in their terminal. The tool can:
- List all supported tools and the number of flags known for each.
- Display all available flags and options for a specific tool in a table format.
- Explain specific flags for a given tool, indicating if a flag is unknown.
</Project_Overview>
