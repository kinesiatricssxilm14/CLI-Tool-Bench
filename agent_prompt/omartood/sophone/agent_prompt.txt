<Project_Overview>
**CLI Tool Name**: somali-phone-cli
**Repository Name**: somali-phone-cli
**Core Functionality Description**:
This is a command-line tool for working with Somali phone numbers. Its core functionalities include:
- Validating if a given number is a valid Somali phone number.
- Formatting numbers into various standard formats (local, E.164, international).
- Identifying the mobile operator (e.g., Hormuud, Somtel) associated with a number.
- Detecting the primary mobile wallet (e.g., EVC, Sahal) for a number.
- Displaying detailed information about operators and mobile wallets.
- Listing all supported operators and wallets.
- Processing a batch of phone numbers from a file.
</Project_Overview>
