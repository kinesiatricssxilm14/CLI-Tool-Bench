<Project_Overview>
**CLI Tool Name**: swagger-coverage-cli
**Repository Name**: swagger-coverage-cli
**Core Functionality Description**:
This is a command-line utility to analyze API test coverage. It compares API specification files (supporting various formats like protocol buffers, GraphQL schemas, and REST API specs) with test collections or test execution reports. The tool calculates the coverage percentage by matching defined API operations against executed or defined tests. It supports processing single or multiple API specification files in one run. Key features include strict validation modes for query parameters and request bodies, the ability to process pre-existing test run reports, and bypassing specification validation for malformed spec files. The final output is a summary printed to the console and a detailed, interactive HTML report.
</Project_Overview>
