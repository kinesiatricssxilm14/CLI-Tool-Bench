<Project_Overview>
**CLI Tool Name**: sec-scanner
**Repository Name**: sec-scanner
**Core Functionality Description**:
A security scanner CLI tool. It recursively scans a given directory for specific JSON settings files (`.claude/settings.json` and `.claude/settings.local.json`). It analyzes an array of approved commands within these files (specifically under `permissions.allow`) and flags dangerous patterns that could pose a security risk. The tool categorizes findings by severity (HIGH, MEDIUM, LOW) and can filter out low-severity findings.
</Project_Overview>
