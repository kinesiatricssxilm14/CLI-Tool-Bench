<Project_Overview>
**CLI Tool Name**: cartman
**Repository Name**: cartman
**Core Functionality Description**:
A simple local Certificate Authority (CA) tool. It can initialize a self-signed root CA and issue leaf certificates signed by that CA. Leaf certificates can be configured with specific DNS names and/or IP addresses, making it suitable for securing network traffic in development and test environments.
