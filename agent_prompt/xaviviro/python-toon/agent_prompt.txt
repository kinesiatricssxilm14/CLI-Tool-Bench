<Project_Overview>
**CLI Tool Name**: toon
**Repository Name**: toon
**Core Functionality Description**:
This project involves creating a command-line tool for converting data between JSON and a custom format called TOON (Token-Oriented Object Notation). TOON is a compact data format that uses indentation for structure, similar to YAML, and a CSV-like format for tabular data.

The core functionality of the CLI tool is to:
1.  **Encode**: Convert JSON data into TOON format. The tool should automatically detect the need to encode when the input file has a `.json` extension.
2.  **Decode**: Convert TOON data back into JSON format. The tool should automatically detect the need to decode when the input file has a `.toon` extension.
3.  **Handle Standard I/O**: Read input from `stdin` and write output to `stdout` when the input argument is `-`.
4.  **Customization**: Allow users to customize the encoding process, including setting the indentation size, the delimiter for arrays (comma, tab, or pipe), and adding a special marker to array length indicators.
5.  **Forced Mode**: Provide flags to explicitly force encoding (`--encode`) or decoding (`--decode`), overriding the automatic detection based on file extension.
6.  **Validation Control**: Offer an option to disable strict validation (`--no-strict`) when decoding.
</Project_Overview>
