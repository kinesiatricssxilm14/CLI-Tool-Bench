<Project_Overview>
CLI Tool Name: uvenv
Repository Name: uvenv
Core Functionality Description:
A workflow tool that wraps `uv` to manage Python project dependencies using requirements files. It simplifies dependency management by automatically creating a virtual environment (via `uv`) if one does not exist, locking dependencies from an input file into a lockfile with exact versions, and installing packages from the lockfile into the isolated virtual environment.
</Project_Overview>
