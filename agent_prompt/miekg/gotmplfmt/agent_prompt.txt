<Project_Overview>
**CLI Tool Name**: gotmplfmt
**Repository Name**: gotmplfmt
**Core Functionality Description**:
This is a CLI tool for formatting Go template files that contain HTML. The tool reads unformatted template content from standard input and outputs a properly indented and formatted version to standard output. The formatting logic is based on tokenizing the input and applying indentation rules. Indentation is done using tabs. An extra newline is introduced before a `{{block}}` or `{{define}}` statement.
</Project_Overview>
