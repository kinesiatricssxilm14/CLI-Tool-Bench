<Project_Overview>
**CLI Tool Name**: mcgf
**Repository Name**: mcgf
**Core Functionality Description**:
A command-line tool for forecasting future values from time-series data stored in a CSV file. The tool reads historical data, where each row represents an observation of a specific 'gene' (identifier) at a given 'time_index' with a certain 'frequency'. It can then predict future frequencies for these genes.

The tool supports two forecasting models:
1.  **Linear Trend (`trend`)**: Fits a simple linear regression model to the historical data of each gene. This is the default method.
2.  **Moving Average (`ma`)**: Calculates the average of the last `k` observations for each gene.

The user can specify the input CSV file, filter for a single gene, choose the forecasting method, set the forecast horizon (number of steps ahead to predict), and define the window size for the moving average model. The results are displayed in a neatly formatted table in the console.
</Project_Overview>
