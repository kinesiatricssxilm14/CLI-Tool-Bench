<Project_Overview>
**CLI Tool Name**: gogen-structconv
**Repository Name**: gogen-structconv
**Core Functionality Description**:
This is a Go code generation tool that automatically creates conversion functions between two struct types. It scans Go source files for special comments (`// gogen-structconv:generate`) and a corresponding function variable declaration to determine the source and destination types. The tool supports two modes: a default shallow copy mode ("conv" mode) and a deep copy mode (activated by a `// gogen-structconv:copy` comment). It can also automatically convert between string and integer types if the `-strconv` flag is provided.
</Project_Overview>
