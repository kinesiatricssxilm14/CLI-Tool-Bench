<Project_Overview>
**CLI Tool Name**: nf-metro
**Repository Name**: nf-metro
**Core Functionality Description**:
The core functionality of this tool is to generate metro-map-style SVG diagrams from Mermaid graph definitions that are extended with special `%%metro` directives. The tool is designed to visualize workflows as transit-style maps.

It provides the following capabilities:
- **Render**: Converts a `.mmd` definition file into an SVG image, with options to control theme, dimensions, spacing, animation, and more.
- **Validate**: Checks a `.mmd` file for syntax and structural errors without generating an SVG.
- **Info**: Parses a `.mmd` file and prints a summary of its components, such as sections, lines, and stations.
- **Convert**: Transforms a graph definition from a different, simpler format into the tool's specialized `.mmd` format.
</Project_Overview>
