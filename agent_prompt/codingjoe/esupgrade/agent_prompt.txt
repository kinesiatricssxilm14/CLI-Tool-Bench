<Project_Overview>
**CLI Tool Name**: esupgrade
**Repository Name**: esupgrade
**Core Functionality Description**:
This is a CLI tool that automatically upgrades JavaScript, TypeScript, and jQuery code to use modern syntax and APIs. It processes specified files and applies transformations to modernize the code.

The tool supports different sets of transformations based on a "baseline" level, which can be specified via a flag. It also has a special mode to enable transformations for jQuery code.

Based on the provided flags, the tool can operate in one of three modes:
1.  **Diff Mode (default)**: Prints a diff of the proposed changes to standard output without modifying the files.
2.  **Write Mode (`--write`)**: Modifies the files in-place with the upgraded code.
3.  **Check Mode (`--check`)**: Reports which files need upgrading and exits with a non-zero code if changes are found, but does not write changes or print diffs.
</Project_Overview>
