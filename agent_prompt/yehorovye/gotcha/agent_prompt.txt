<Project_Overview>
CLI Tool Name: gotcha
Repository Name: gotcha
Core Functionality Description:
A minimal system fetch CLI tool that displays basic system information (such as OS, kernel, memory, uptime, shell, desktop, terminal, packages, and disk usage) alongside an ASCII art representation of the operating system distribution. It operates with 0 external dependencies. The tool supports customization through a configuration file to disable specific fields, change the divider string, or specify disk mounts. It also allows overriding the displayed distribution ASCII art via command-line flags and complies with the `NO_COLOR` specification to disable colored output.
