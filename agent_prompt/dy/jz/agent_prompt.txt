<Project_Overview>
**CLI Tool Name**: jz
**Repository Name**: jz
**Core Functionality Description**:
This is a command-line tool for a minimal, modern, functional subset of JavaScript that compiles to pure WebAssembly (WASM). The tool provides functionalities to:
1.  Evaluate simple JavaScript expressions or entire JS files directly.
2.  Compile JavaScript files into WebAssembly Text Format (`.wat`).
3.  Compile JavaScript files into WebAssembly binary format (`.wasm`).
4.  Compile and immediately run a JavaScript file.
The core idea is to translate a subset of JS into highly efficient WASM with no runtime, garbage collection, or overhead.
</Project_Overview>
