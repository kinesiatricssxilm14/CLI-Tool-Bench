<Project_Overview>
**CLI Tool Name**: pbi-doc-gen
**Repository Name**: pbi-doc-gen
**Core Functionality Description**:
This is a CLI tool that automatically extracts metadata from Power BI template (`.pbit`) files to generate comprehensive documentation. It is designed to help data engineers, analysts, and consultants quickly understand and document Power BI models.

The tool can:
- Process a single `.pbit` file to generate documentation.
- Process multiple `.pbit` files in batch mode using a file pattern.
- Compare two versions of a model and report the differences in measures and relationships.
- Generate documentation in multiple formats:
    - Human-readable Markdown (`.md`).
    - Structured model metadata (`metadata.json`).
    - AI-optimized context for LLMs (`agent_context.json`).
    - Line-delimited JSON for embeddings/RAG (`model_context.jsonl`).
- Support multiple output languages (English and Spanish).
- Provide verbose logging for debugging purposes.
</Project_Overview>
