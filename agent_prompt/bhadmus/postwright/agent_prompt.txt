<Project_Overview>
CLI Tool Name: postwright
Repository Name: postwright
Core Functionality Description:
Converts Postman collections into Playwright test scripts. It creates a `variables.js` (or `variables.ts`) and `variables.json` file to manage saved variables. It offers basic post-response assertions (status code and response time) and extracts the titles of tests. It supports outputting to a specific directory and choosing between JavaScript (default) and TypeScript formats.
</Project_Overview>
