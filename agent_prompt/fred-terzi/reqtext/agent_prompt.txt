<Project_Overview>
**CLI Tool Name**: reqt
**Repository Name**: reqt
**Core Functionality Description**:
This is a CLI tool for project planning and requirement management using a single Markdown file as the source of truth. The tool allows users to initialize a project structure, and then manage hierarchical items (e.g., features, requirements) directly from the command line. Key functionalities include adding, deleting, editing, and restructuring items (promoting/demoting). The tool automatically handles numbering and hierarchy updates within the Markdown file. It can also generate a separate README.md file based on the contents of the project's main Markdown file.
</Project_Overview>
