<Project_Overview>
**CLI Tool Name**: gt
**Repository Name**: gt
**Core Functionality Description**:
This is a command-line tool for analyzing and displaying folder structures. Its primary function is to generate a tree-like representation of a directory. The tool provides various options to customize the output:
- Control the traversal depth of the directory tree.
- Limit the number of items displayed per directory.
- Include hidden files and display file sizes.
- Sort items by listing files before directories.
- Filter the output to show only directories or only files classified as "code".
- Enhance visual output with emojis.

Additionally, the tool can export the project's structure and file contents into structured formats like JSON or Markdown. It also has the capability to create a compressed ZIP archive of the project, with an option to respect the rules defined in a `.gitignore` file to exclude specific files and directories from the archive.
</Project_Overview>
